Eight Built-In Pages

Everything you reach for, one click away

Scroll over the notch or click the dots on the right to glide between pages. Turn any page on or off and reorder them in Settings.

Clock & World Places

Big time and date with clickable world cities (London, New York, Tokyo, or any city worldwide).

Weather

Current temp, feels-like, high/low, wind, next 7 hours and 6 days with rain chance, plus °C/°F toggle.

Now Playing

Artwork, seek bar with time remaining, shuffle, prev/play/next, and repeat via Windows Media or Linux MPRIS.

Focus Timer

Pomodoro cycles or single Zen sessions with on-the-fly white, pink, or brown noise generation.

Notes

Searchable, pinnable note cards where lines starting with [ ] become clickable checkboxes.

Clipboard History

Text, links, images, and files with search, pinning, and pause—automatically skipping password managers.

Volume Mixer

Master knob, per-app faders with icons, click-to-mute, mic & speaker mute, and active output device.

Settings & About

Reorder pages, manage login autostart, full-screen tuck behavior, and opt-in daily update checks.

Cross-Platform Native

First-class on Windows and Linux

Same dark hardware-notch look, same 8 pages, and shared core services—built natively for each desktop’s audio, media, and windowing stack.

Windows

WPF · .NET 10

Ships as a single self-contained EasyNotch.exe for 64-bit Windows 10 (1809+) and Windows 11. No installer or .NET runtime required.

  • Tool window stays out of Alt+Tab and the taskbar with click-through edges
  • Windows Core Audio per-app mixer & GlobalSystemMediaTransportControls
  • Shrinks to a thin line over full-screen apps until you hover it
  • Follows Windows’ native “Animation effects” setting

Linux

Avalonia · X11 / Wayland

Self-contained EasyNotch-linux-x64.tar.gz installs into ~/.local/opt/easy-notch with zero root needed—tested on KDE Plasma 6 (Wayland), GNOME, Cinnamon, XFCE, and tiling WMs.

  • MPRIS D-Bus media controls for Spotify, Firefox, Chrome, VLC, mpv
  • PulseAudio & PipeWire mixer via pactl and ambient noise via pacat
  • StatusNotifierItem tray icon (works on KDE & GNOME AppIndicator)
  • Respects x-kde-passwordManagerHint to keep copied secrets private
Get Easy Notch

Up and running in under a minute

Download the latest v0.2.0 release for Windows or Linux, or build directly with the .NET 10 SDK.

Requires 64-bit Windows 10 (1809) or Windows 11. No .NET runtime needed.

  1. Download EasyNotch.exe from the latest GitHub release.
  2. Move it to a permanent folder (e.g. Documents\Easy Notch) so login autostart always finds it.
  3. Double-click it. If Windows SmartScreen warns (unsigned binary), choose More info → Run anyway.
# Optional: jump straight to a specific page from CLI
EasyNotch.exe --open mixer
Toggle Start with Windows any time in Settings. Download EasyNotch.exe →

Works on 64-bit X11 or Wayland (with XWayland). Installs per-user under ~/.local/opt/easy-notch with no sudo required. 

cd ~/Downloads
tar -xzf EasyNotch-linux-x64.tar.gz
./EasyNotch-linux-x64/install.sh
Use --no-autostart to skip login launch, or run ~/.local/opt/easy-notch/uninstall.sh to remove. Download Linux Tarball →

Easy Notch runs without extra packages, while Volume Mixer and Focus noise use pactl and pacat (which also work with PipeWire):

Distribution Command
Ubuntu, Mint, Pop!_OS, Debian sudo apt install pulseaudio-utils
Fedora (Workstation, KDE) sudo dnf install pulseaudio-utils
Arch, Manjaro, EndeavourOS, CachyOS sudo pacman -S --needed libpulse
openSUSE (Tumbleweed, Leap) sudo zypper install pulseaudio-utils
On Sway, Hyprland, or i3: add a float rule for window class easy-notch.

Requires the .NET 10 SDK. 

# Windows (self-contained single .exe)
dotnet publish -c Release -o out

# Linux (Avalonia app & self-contained tarball)
dotnet run --project linux
linux/publish.sh
Core services (Notes, Weather, Update Check) are shared between Windows and Linux. Browse Repository →
Privacy by Design

Your data stays on your machine

No accounts, no cloud sync walls, and no telemetry. Everything lives in one transparent folder on your disk.

01 / LOCAL STORAGE

Notes & Clipboard Stay Local

All settings, notes, and clipboard history are saved strictly in %LOCALAPPDATA%\EasyNotch on Windows or ~/.local/share/easy-notch on Linux.

02 / SECRET PROTECTION

Skips Password Managers

Automatically ignores clipboard entries marked private or secret by password managers (including KeePassXC’s x-kde-passwordManagerHint on Linux).

03 / MINIMAL NETWORK

Keyless Weather & Opt-In Updates

Uses keyless Open-Meteo for forecasts (cached offline) and GitHub’s public releases API at most once a day—never auto-downloading binaries.
